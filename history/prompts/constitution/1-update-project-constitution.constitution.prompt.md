## 1. Project Context & Purpose

The future of software development is **AI-native and spec-driven**.
As AI agents such as Claude Code become more capable, the role of the engineer evolves from **syntax writer** to **system architect**.

This project implements that philosophy by evolving a Todo application across five structured phases, starting from a simple console program and culminating in a fully cloud-native, AI-powered conversational system deployed on Kubernetes.

This project is developed as part of **Hackathon II: Spec-Driven Development**, aligned with Panaversity's mission to teach cutting-edge AI-native engineering.
